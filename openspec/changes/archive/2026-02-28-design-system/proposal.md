# Proposal: Design System

## Why

L'objectiu és crear un Design System dins del projecte que permeti mantenir una interfície consistent i facilitar futures modificacions. Actualment alguns elements visuals (colors, botons, espaiats, components) varien entre pantalles, cosa que pot generar inconsistència visual, major complexitat en el manteniment i dificultat per escalar el producte.

## What

Centralitzar tokens de disseny, crear components reutilitzables (o documentar els existents), garantir consistència visual i reduir el temps de desenvolupament de noves funcionalitats.

**MVP:**
- Design tokens centralitzats (colors, espaiat, tipografia, border-radius)
- Components de botó ja existents (PrimaryButton, SecondaryButton, GhostButton) — documentar i consolidar
- Components d'input: TextInput, Textarea
- Documentació bàsica del design system
