# reading-goals-insights (delta)

## NEW Requirements

### Requirement: Encoratjaments block UI consistency

The "Encoratjaments" block on the home page SHALL use the same title typography and icon styling as the other dashboard blocks (Ratxa, Aquest mes, Objectiu anual, Progrés global de lectura, Llegint ara).

- Title SHALL use `text-sm font-medium text-slate-600`.
- Icon SHALL use `w-6 h-6 text-primary-600`.
- Layout SHALL use the same gap between icon and title as the other blocks.
