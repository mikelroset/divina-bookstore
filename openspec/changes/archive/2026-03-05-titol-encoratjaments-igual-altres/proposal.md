# Proposal: Bug fix – Títol encoratjaments igual que els altres

## Problema

El títol del bloc "Encoratjaments" a la pàgina d'inici té una tipografia diferent als altres blocs (Ratxa, Aquest mes, Progrés global de lectura, Llegint ara, etc.).

## Solució

Unificar el format del títol del bloc Encoratjaments amb la resta: mateixa classe CSS (`text-sm font-medium text-slate-600`), mateix gap i mida d'icona (`w-6 h-6`).
