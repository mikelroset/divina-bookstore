# Proposal: UT & coverage

## Per què (Why)

L'objectiu és garantir que l'aplicació sigui estable, segura i fiable mitjançant la implementació d'un sistema complet de tests automatitzats i un nivell adequat de test coverage.

Els tests han de permetre:
- detectar errors abans de desplegar noves funcionalitats
- prevenir regressions
- garantir que les funcionalitats crítiques funcionen correctament

## Què (What)

El sistema de testing ha d'incloure diferents nivells:

- **Tests unitaris:** per validar funcions i lògica de negoci
- **Tests d'integració:** per comprovar la interacció entre diferents parts del sistema (API, base de dades, serveis)
- **Tests end-to-end (E2E):** per validar fluxos complets d'usuari

També es definirà un objectiu mínim de cobertura de tests per garantir la qualitat del codi.

## User story

Com a equip de desenvolupament, vull tenir un sistema de tests automatitzats amb un bon nivell de cobertura, per tal de garantir que l'aplicació sigui estable, segura i fàcil de mantenir.
